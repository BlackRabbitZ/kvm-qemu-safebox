# Attribution

Dieses Projekt nutzt **Apache License 2.0** zusammen mit einer `NOTICE`-Datei.

Damit ist bei der Weitergabe abgeleiteter Werke unter anderem vorgesehen, dass relevante Attribution-Hinweise aus `NOTICE` in lesbarer Form erhalten bleiben. Das `NOTICE` verweist auf das Original-Repository.

Vor der ersten Veröffentlichung unbedingt ersetzen:

- `YOUR_NAME`
- `YOUR_GITHUB_USERNAME`

Die Apache-2.0-Lizenz ist eine Standardlizenz. Dieses Repository stellt keine Rechtsberatung dar.
